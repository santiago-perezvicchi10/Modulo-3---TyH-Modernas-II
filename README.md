# Modulo-3---TyH-Modernas-II
# Taller de fotografía

## Descripción del proyecto
En este trabajo aplicamos técnicas de fotografía forense para registrar y analizar evidencias visuales en ingeniería. A través de un taller, comprobamos que una captura correcta y el análisis de sus parámetros técnicos permiten usar las imágenes como prueba documental y sustento de decisiones técnicas.

El análisis se divide en dos áreas de aplicación:
Análisis de falla de material: estudio pericial de la rotura de una probeta de acero corrugado. Se interpreta cómo se produjo la rotura (transición dúctil-frágil, fatiga y corrosión) y se extraen los metadatos EXIF de las fotos para asegurar la trazabilidad legal y técnica de la evidencia.
Análisis técnico de parámetros fotográficos: evaluación crítica de una fotografía documental de un evento. Con los conceptos del taller, se analizan la iluminación, la composición, la profundidad de campo, la saturación y el contexto del entorno.
